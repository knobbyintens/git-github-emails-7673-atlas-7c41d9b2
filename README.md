# Service Atlas docs

Documentation for the Service Atlas ingest platform.

- `catalog/index.md` is the locator index for the source tree. Each entry maps
  a module anchor to the line that currently carries it.
- `catalog/owners.yaml` records ownership and the documentation tier of every
  component.
- `docs/notes/` holds the per-component review notes.

Anchor convention in source files:

    # atlas-anchor: <anchor-key>

Line numbers in the index refer to the anchor comment line itself, not to the
line where the surrounding function starts.
